# Terminal Bench 2.0 Task

## Overview
This project demonstrates basic Linux terminal operations, shell scripting, and environment setup using WSL (Windows Subsystem for Linux).

The task involved:

- Setting up Ubuntu WSL on Windows
- Creating and editing shell scripts
- Creating required files using Bash
- Running automated test scripts
- Debugging file path and permission issues
- Verifying outputs using pytest
- Packaging the final submission into a ZIP archive

## Technologies Used
- Bash
- Ubuntu WSL
- VS Code
- Python / pytest
- Linux terminal commands

## Key Commands Used

```bash
wsl --install
bash solution/solve.sh
cat app/hello.txt
pytest tests/test_outputs.py
